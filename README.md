# Hangman - Java

A simple Hangman game built with Java.

## Features

* Guess the hidden word letter by letter
* 5 maximum failed attempts
* Displays correctly guessed letters
* Tracks used letters
* Detects win and game over conditions
* Input validation

## Technologies

* Java 21
* Java Scanner
* Arrays
* Loops
* Conditions
* Basic Java programming concepts

## How to run

Compile the program:

```bash
javac Main.java
```

Run the program:

```bash
java Main
```

## Project

This project was created as a Java practice project to review programming fundamentals and build a small project for GitHub.
